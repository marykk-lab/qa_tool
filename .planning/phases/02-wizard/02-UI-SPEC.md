## Color

### Palette

| Role | Hex | CSS Variable | Tailwind utility | Usage |
|------|-----|--------------|------------------|-------|
| Dominant (60%) | `#0a0a0a` | `--background` | `bg-background` | Full page background |

| Accent (10%) | `#3ecf8e` | `--primary` | `bg-primary`, `text-primary` | See reserved list below |
| Foreground | `#ededed` | `--foreground` | `text-foreground` | Primary text on dark background |
| Muted foreground | `#a1a1aa` | `--muted-foreground` | `text-muted-foreground` | Progress label, placeholder text, hints |
| Border | `#27272a` | `--border` | `border-border` | Card borders, separator lines, input outlines |
| Disabled surface | `#1a1a1a` | — | `bg-[#1a1a1a]` | Disabled button/checkbox background |
| Disabled text | `#52525b` | — | `text-[#52525b]` | Disabled label text |
| Destructive | `#ef4444` | `--destructive` | `text-destructive` | Error/validation messages only |

### Accent Reserved For (explicit list — no other elements use `#3ecf8e`)

1. "Далі" (primary action) button background and hover
2. Progress bar fill (`value` color)
3. Checked RadioGroupItem indicator dot
4. Checked Checkbox fill
5. Focus ring color on interactive elements (`ring-primary`)
6. "Готово" completion state icon/badge

Accent is NOT used for: card backgrounds, page headings, body text, borders, or "Назад" button.

### CSS Variable Overrides for Feedboon Dark Theme

Add to `globals.css` inside `:root` (unconditional — always dark, no light mode toggle):

```css
:root {
  --background: oklch(7.84% 0 0);          /* #0a0a0a */
  --foreground: oklch(92.94% 0 0);          /* #ededed */
  --card: oklch(9.41% 0 0);                 /* #171717 */
  --card-foreground: oklch(92.94% 0 0);     /* #ededed */
  --popover: oklch(9.41% 0 0);             /* #171717 */
  --popover-foreground: oklch(92.94% 0 0); /* #ededed */
  --primary: oklch(76.86% 0.168 161.1);    /* #3ecf8e */
  --primary-foreground: oklch(7.84% 0 0);  /* #0a0a0a — dark text on green */
  --secondary: oklch(13.73% 0 0);          /* ~#232323 — slightly lighter than card */
  --secondary-foreground: oklch(92.94% 0 0);
  --muted: oklch(15.29% 0 0);              /* ~#272727 */
  --muted-foreground: oklch(63.13% 0 0);   /* #a1a1aa */
  --accent: oklch(13.73% 0 0);
  --accent-foreground: oklch(92.94% 0 0);
```

## Interaction States

### RadioGroup Items (Step 1 — Project Type, Step 2 — Platform)

Each option is rendered as a full-width clickable row (not just the radio dot):

| State | Visual |
|-------|--------|
| Default | `border border-border rounded-md bg-card p-4` |
| Hover | `border-primary/50 bg-card/80 cursor-pointer` |
| Selected | `border-primary bg-card ring-1 ring-primary` with indicator dot filled `text-primary` |
| Focus-visible | `outline-none ring-2 ring-ring ring-offset-2 ring-offset-background` |
| Disabled | `opacity-50 cursor-not-allowed` |

### Checkbox Items (Step 3 — Modules, Step 4 — Detail booleans)

Each checkbox + label pair is a full-width row:

| State | Visual |
|-------|--------|
| Default | `border border-border rounded-md bg-card p-4` row |
| Hover | `border-primary/40 bg-card/80 cursor-pointer` |
| Checked | Checkbox fill: `bg-primary border-primary`; checkmark: `text-primary-foreground` |
| Focus-visible | `ring-2 ring-ring ring-offset-2 ring-offset-background` on checkbox element |
| Disabled | `opacity-50 cursor-not-allowed` |

### Buttons

| Variant | Usage | Tailwind |
|---------|-------|---------|
| Primary (default) | "Далі" / "Готово — перейти до результатів" | `bg-primary text-primary-foreground hover:bg-primary/90` |
| Secondary (outline) | "Назад" | `border border-border bg-transparent text-foreground hover:bg-secondary hover:text-foreground` |
| Ghost | Not used in this phase | — |

| State | "Далі" (Primary) | "Назад" (Outline) |
|-------|------------------|-------------------|
| Default | `bg-primary text-primary-foreground` | `border-border text-foreground` |
| Hover | `bg-primary/90` | `bg-secondary text-foreground` |
| Focus-visible | `ring-2 ring-ring ring-offset-2` | same |
| Disabled | `opacity-50 cursor-not-allowed` (when required selection missing) | `opacity-50 cursor-not-allowed` (on step 1) |
| Active/pressed | `bg-primary/80` | `bg-secondary/80` |

Button sizing: `h-10 px-6 text-sm font-semibold rounded-md` (new-york preset default).

### Sonner Toast (Validation)

- Toast appears when user attempts to advance without a required selection
- Theme: dark (`theme="dark"` on `<Toaster>`)
- Position: `bottom-right`
- Style: `bg-card border-border text-foreground` (matches Feedboon dark)

## Accessibility Requirements

- All RadioGroupItem and Checkbox rows must meet 44px minimum touch target height (`min-h-[44px]`)
- All interactive elements must have visible focus rings using `ring-ring` color
- Checkbox and RadioGroup use Radix UI primitives — `aria-checked`, `role="radio"`, `role="checkbox"` handled by the library
- Progress bar uses `role="progressbar"` with `aria-valuenow`, `aria-valuemin`, `aria-valuemax` — handled by Radix Progress
- Toast notifications (Sonner) are announced via `role="status"` / `aria-live` — handled by Sonner
