Step routing rules (per D-01, D-09):
- Steps 1, 2, 3: fixed (unchanged)
- Steps 4 through `3 + state.modules.length`: module sub-steps. Step `3 + k` (k from 1 to N) maps to `state.modules[k-1]` (the k-th selected module in selection order).
- Step `3 + state.modules.length + 1` (i.e., `totalSteps + 1`): completion / ResultsView

Completion detection: `isCompletion = currentStep > totalSteps` OR equivalently `currentStep === totalSteps + 1`. Pass `isCompletion` to WizardNav as before. ResultsView renders when `isCompletion`.

handleNext rewrite:
- Step 1: guard `!state.projectType` → toast.error("Будь ласка, оберіть тип проекту"); return
- Step 2: guard `!state.platform` → toast.error("Будь ласка, оберіть платформу"); return
- Step 3: guard `state.modules.length === 0` → toast.error("Оберіть принаймні один модуль для тестування"); return. If guard passes → `setCurrentStep(prev => prev + 1)`.
- Steps 4..3+N (sub-steps): always advance → `setCurrentStep(prev => prev + 1)`. No guard needed (features are optional per D-05).
- Default: `setCurrentStep(prev => prev + 1)`.

handleBack rewrite:
- If `isCompletion` (currentStep === totalSteps + 1) → go back to step `totalSteps` (last sub-step, or step 3 if 0 modules).
- Otherwise: `setCurrentStep(prev => Math.max(1, prev - 1))`.

Step render in JSX — use the following structure (replace the old step 4/5 branches):
```jsx
{currentStep === 1 && <StepProjectType ... />}
{currentStep === 2 && <StepPlatform ... />}
{currentStep === 3 && <StepModules ... />}
{state.modules.map((moduleId, index) => {
  const subStep = 4 + index;
  return currentStep === subStep ? (
    <StepModuleFeatures
      key={moduleId}
      moduleId={moduleId}
      moduleName={MODULE_DISPLAY_NAMES[moduleId] ?? moduleId}
      features={MODULE_FEATURES[moduleId] ?? []}
      selected={state.moduleFeatures[moduleId] ?? []}
      onChange={(v) =>
        updateState({ moduleFeatures: { ...state.moduleFeatures, [moduleId]: v } })
      }
    />
  ) : null;
})}
{isCompletion && (
  <ResultsView
    state={state}
    allCases={initialCases}
    onRestart={() => {
      setState(INITIAL_WIZARD_STATE);
      setCurrentStep(1);
    }}
  />
)}
```
