### Context

The results screen replaces the `{currentStep === 5}` placeholder div in `Wizard.tsx` (lines 93–105). It renders inside the existing `<Card>` shell. WizardNav remains above the content — `isCompletion={true}` hides the "Далі" button. The action buttons (Copy, Download, Export, Restart) are rendered inside the results view, not in WizardNav.


```html
<div class="w-full overflow-x-auto rounded-md border border-border">
  <table class="w-full text-sm text-foreground">
    <thead>
      <tr class="bg-card border-b border-border">
        <th class="px-4 py-3 text-left text-sm font-normal text-muted-foreground w-[110px]">ID</th>
        <th class="px-4 py-3 text-left text-sm font-normal text-muted-foreground">Назва</th>
        <th class="px-4 py-3 text-left text-sm font-normal text-muted-foreground">Передумови</th>

        <th class="px-4 py-3 text-left text-sm font-normal text-muted-foreground">Очікуваний результат</th>
        <th class="px-4 py-3 text-left text-sm font-normal text-muted-foreground w-[110px]">Пріоритет</th>

    </thead>

      {cases.map(tc => (
        <tr class="border-b border-border last:border-0 hover:bg-secondary/30">
          <td class="px-4 py-3 text-sm font-normal align-top text-muted-foreground">{tc.ID}</td>
          <td class="px-4 py-3 text-sm font-normal align-top text-foreground">{tc.Назва}</td>
          <td class="px-4 py-3 text-sm font-normal align-top text-foreground">{tc.Передумови}</td>
          <td class="px-4 py-3 text-sm font-normal align-top">
            <ol class="list-decimal list-inside space-y-1 text-foreground">
              {tc.Кроки.map((step, i) => <li key={i}>{step}</li>)}
            </ol>
          </td>

```

Notes:
- `overflow-x-auto` on the wrapper ensures horizontal scroll on tablet if content exceeds viewport
- `align-top` on all `<td>` cells — content aligns to top of row, not middle
- ID column uses `text-muted-foreground` to visually de-emphasize the ID vs. the case name
- Row hover: `hover:bg-secondary/30` — subtle, does not interfere with text legibility
- No row selection or click interaction — table is read-only display

## Priority Badge Colors

Use shadcn `Badge` with `variant="outline"` base, override via `className` prop and `cn()`. Do not modify `badge.tsx`.

| Priority | Background | Text | Border |
|----------|-----------|------|--------|
| `High` | `bg-red-950/60` | `text-red-400` | `border border-red-800` |
| `Medium` | `bg-amber-950/60` | `text-amber-400` | `border border-amber-800` |
| `Low` | `bg-zinc-800/60` | `text-zinc-400` | `border border-zinc-700` |

Component pattern (inherited exactly from Phase 2 UI-SPEC):

```tsx
// PriorityBadge.tsx (new small component)
import { Badge } from "@/components/ui/badge";
import { cn } from "@/lib/utils";

const PRIORITY_STYLES: Record<string, string> = {
  High:   "bg-red-950/60 text-red-400 border-red-800",
  Medium: "bg-amber-950/60 text-amber-400 border-amber-800",
  Low:    "bg-zinc-800/60 text-zinc-400 border-zinc-700",
};

export function PriorityBadge({ priority }: { priority: "High" | "Medium" | "Low" }) {
  return (
    <Badge
      variant="outline"
      className={cn("text-xs font-normal", PRIORITY_STYLES[priority])}
    >
      {priority}
    </Badge>
  );
}
```

Note: Badge text stays in English ("High" / "Medium" / "Low") — these are the values from the JSON data source (`Пріоритет` field). Do not translate badge labels.

## Action Buttons

### Layout

Buttons render in a `flex flex-wrap gap-4` row below all module blocks, with `mt-12` top margin.

Desktop: all 4 buttons on one row (left to right in declaration order).
Tablet: if row overflows, wraps to 2 rows of 2.

### Button Order (left to right)

1. Скопіювати Markdown
2. Завантажити .md
3. Експорт до Notion (.csv)
4. Почати заново

### Button Specs

| Button | Ukrainian label | Variant | Tailwind overrides | Action |
|--------|----------------|---------|-------------------|--------|
| Copy Markdown | `Скопіювати Markdown` | `default` (primary) | `bg-primary text-primary-foreground hover:bg-primary/90` | Copy Markdown to clipboard → Sonner toast |
| Download .md | `Завантажити .md` | `outline` | `border-primary text-primary hover:bg-primary/10` | Download `.md` file |
| Export Notion | `Експорт до Notion (.csv)` | `outline` | `border-border text-foreground hover:bg-secondary` | Download `.csv` file |
| Restart | `Почати заново` | `ghost` | `text-muted-foreground hover:text-foreground hover:bg-secondary/50` | Reset wizard to step 1 |

Button sizing: `h-10 px-6 text-sm font-semibold rounded-md` — same as Phase 2 buttons.

### Reasoning

- "Скопіювати Markdown" is the primary action (most common use case) — receives accent background.
- "Завантажити .md" is secondary but closely related — receives accent outline.
- "Експорт до Notion (.csv)" is tertiary — neutral outline, not accent-colored.
- "Почати заново" is a soft-destructive reset — ghost variant, muted text, not red (no data is permanently lost).

### Focus States

All buttons: `focus-visible:ring-2 focus-visible:ring-ring focus-visible:ring-offset-2` — inherited from shadcn Button component defaults.

## Interaction States

### Copy Markdown Button

| State | Visual |
|-------|--------|
| Default | `bg-primary text-primary-foreground` |
| Hover | `bg-primary/90` |
| Active/pressed | `bg-primary/80` |

| After copy (success) | Sonner toast appears; button returns to default state |

### Download / Export Buttons

No loading state needed — file download is synchronous. Button fires `window.URL.createObjectURL` and triggers anchor click; no visual state change beyond hover.

### Почати заново

No confirmation dialog. "Почати заново" is not a destructive action in the data-loss sense — WizardState is ephemeral (never persisted). Soft reset: immediate state clear and step 1 navigation.

- Table headers use `<th scope="col">` — required for screen reader column association
