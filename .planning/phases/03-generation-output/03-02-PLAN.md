**Generation logic — filterCasesForModule function (define above the component):**

This function accepts `(moduleId: string, state: WizardState, allCases: TestCase[]): TestCase[]`.

1. Gather prefixes: `const prefixes = MODULE_TC_PREFIXES[moduleId] ?? [];`
2. If `moduleId === "checkout"` and `state.checkoutDetails?.hasPromoCode === true`, push `PROMO_TC_PREFIX` into a copy of the prefixes array.
3. Filter `allCases` to those whose `tc.ID` starts with any prefix in the array: `prefixes.some(p => tc.ID.startsWith(p))`.
4. Apply ID-based exclusions for detail flags (use Array `.filter()` chained on the prefix-filtered array):
   - `checkout` module, `hasGuestCheckout === false`: exclude `tc.ID === "TC-CHK-003"`
   - `checkout` module, `hasPromoCode === false`: also exclude `tc.ID === "TC-CHK-005"` (the promo-code application test in checkout.json)
   - `search` module, `hasAutoComplete === false`: exclude `tc.ID === "TC-SRCH-003"`
   - `search` module, `hasFiltersInResults === false`: exclude `tc.ID === "TC-SRCH-004"`
   - `contact-form` module, `hasFileUpload === false`: exclude `tc.ID === "TC-FORM-003"`
   - `contact-form` module, `hasCaptcha === false`: exclude `tc.ID === "TC-FORM-004"`
   - `multilang` module, `languageCount === "2"`: exclude `tc.ID === "TC-LANG-003"` (three-language test)
   - auth module: no exclusions (no auth detail flags have corresponding case IDs to exclude in auth.json)
5. Return the filtered array. When `prefixes` is empty (modules with no JSON: filter, compare, wishlist, subscription, gallery), return `[]` immediately without scanning allCases.

Detail state access pattern (null-safe):
- `state.checkoutDetails?.hasGuestCheckout` — only truthy exclusion fires when explicitly `=== false`
- `state.searchDetails?.hasAutoComplete` — same pattern
- If detail object is null (user skipped detail step), D-09 applies: all cases included (no exclusion fires)

**Markdown generation function — buildMarkdown (define above component):**

Accepts `(modules: string[], state: WizardState, allCases: TestCase[]): string`.

Header line: `# Результати тестування — ${projectTypeLabel} — ${todayISO}`
where `projectTypeLabel = state.projectType === "ecommerce" ? "E-commerce" : "Інформаційний сайт"`
and `todayISO = new Date().toISOString().slice(0, 10)`.

For each module in `modules` (preserving selection order):
1. Call `filterCasesForModule(moduleId, state, allCases)`.
2. If cases is empty, skip this module.
3. Append `\n\n## ${MODULE_DISPLAY_NAMES[moduleId]} (${cases.length})\n`.
4. Append table header: `| ID | Назва | Передумови | Кроки | Очікуваний результат | Пріоритет |\n|----|-------|------------|-------|----------------------|-----------|\n`
5. For each case, append a row. Кроки column: `tc.Кроки.map((s, i) => `${i + 1}. ${s}`).join("<br>")` (D-10).
6. Wrap each cell value with a pipe, joining with ` | `.

Return the full string.

function downloadFile(content: string, filename: string, mimeType: string): void {
  const blob = new Blob([content], { type: mimeType });
  const url = URL.createObjectURL(blob);
  const a = document.createElement("a");
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}
