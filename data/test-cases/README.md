# Test Cases Data

Ця папка містить JSON-файли з бібліотекою тест кейсів для QA Test Constructor.

## JSON-схема тест кейсу

Кожен JSON-файл (або масив у файлі) повинен відповідати такій схемі:

```json
{
  "ID": "TC-CAT-001",
  "Назва": "Назва тест кейсу",
  "Передумови": "Умови, що мають виконуватись перед початком тесту",
  "Кроки": [
    "Крок 1: опис дії",
    "Крок 2: опис дії"
  ],
  "Очікуваний результат": "Очікувана поведінка системи після виконання кроків",
  "Пріоритет": "High"
}
```

## Поля схеми

| Поле | Тип | Опис |
|------|-----|------|
| `ID` | string | Унікальний ідентифікатор кейсу у форматі `TC-{PREFIX}-{NUM}` |
| `Назва` | string | Коротка назва тест кейсу |
| `Передумови` | string | Умови, що мають бути виконані до початку тесту |
| `Кроки` | string[] | Масив кроків у вигляді рядків — нумерований список дій |
| `Очікуваний результат` | string | Очікувана поведінка після виконання всіх кроків |
| `Пріоритет` | "High" \| "Medium" \| "Low" | Пріоритет тест кейсу |

## ID-префікси модулів

Для Phase 2 wizard: кожен модуль має свій ID-префікс:

| Префікс | Модуль |
|---------|--------|
| `TC-CAT` | Каталог товарів |
| `TC-PDP` | Сторінка товару (Product Detail Page) |
| `TC-CART` | Кошик |
| `TC-CHK` | Checkout (Оформлення замовлення) |
| `TC-AUTH` | Авторизація / Особистий кабінет |
| `TC-SRCH` | Пошук |
| `TC-BLOG` | Блог |
| `TC-FORM` | Контактна форма |
| `TC-LANG` | Багатомовність |
| `TC-CPN` | Купони / Промокоди |

## Конвенції

- JSON-файли зберігаються у цій папці (`/data/test-cases/`)
- Редагування файлів не потребує перекомпіляції застосунку (GEN-01)
- Нові файли підхоплюються лоадером `src/lib/test-cases.ts`
- Форматування: UTF-8, відступи 2 пробіли
